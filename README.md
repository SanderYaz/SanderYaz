## 👨🏻‍💻 About Me

I am a **Senior Frontend Developer with 6+ years of professional experience** designing and developing frontend architectures for high-traffic SaaS products.

I build modern, maintainable and user-focused solutions with **Angular, React, Next.js, TypeScript and Node.js**. My work focuses on modular architecture, performance optimization, reusable component systems, developer experience, test automation and reliable delivery pipelines.

- 🧩 Frontend architecture and scalable component systems
- ⚡ Web performance, UX and maintainability
- 🧪 Test automation, Appium and developer tooling
- 🚀 CI/CD, Docker, GitHub Actions and cloud platforms
- 🎮 Game development and experimental side projects
