## About me

I am a **Senior Frontend Developer** with **6+ years of professional experience** designing and developing frontend architectures for high-traffic SaaS products.

My work focuses on **scalability, performance, maintainability, testability, and user experience**. I primarily build with **Angular, React, Next.js, TypeScript, and Node.js**, and I also enjoy creating developer tools, automation integrations, and experimental game projects.

- **Engineering:** modular frontend architecture, reusable component systems, performance optimization
- **Product:** SaaS platforms, developer-facing products, cross-device user experiences
- **Quality:** clean code, automated delivery, testing strategy, long-term maintainability
